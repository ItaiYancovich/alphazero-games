Speed test

Times the bots on this device, each playing the rule-based bot as it would play you, in two setups: before (the site as it was: one network worker, full-precision networks) and after (a pool of network workers tuned to this device, 8-bit or full-precision networks, whichever this device runs faster, and an evaluation cache). They run after–before–before–after, so a phone that slows down as it warms up is fair to both.

Takes about 5–9 minutes: first a minute of the bots playing, untimed, so the device is already as warm as it gets in a real game, then the timed rounds, then each network on its own (CPU and, where the browser has one, GPU). Keep this tab in front and the screen on; plugged in and not in low-power mode is best.

Seconds per move at 400 simulations (lower is better); for the v3 bot, which thinks for 2 seconds a move, simulations per second (higher is better).

Each network on its own: milliseconds per position (lower is better), CPU — the fastest of the old setup and the pool — against the GPU — the fastest of the GPU alone (full or half precision) and the GPU sharing the batch with the CPU — at two batch sizes.
